# Dolphin POS — frontend

Prototype FE demo cho Founder (Pet Shop). Hardcoded state, không API.

## Chạy local

```bash
cd products/saas/pos/fe
npm install
npm run dev
```

Mở http://localhost:3012

## Scripts

| Script | Mô tả |
| --- | --- |
| `npm run dev` | Dev server port 3012 |
| `npm run build` | Production build |
| `npm start` | Serve build port 3012 |
